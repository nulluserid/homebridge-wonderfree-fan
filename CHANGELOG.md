# Changelog

## 0.1.0 (2026-10-18)

- Initial public release.
- Local HomeKit control for Wonderfree/Quectel fans (tested with OmniBreeze DC2313R, product keys p11vAZ and p11vkW).
- Fan on/off, five speeds, oscillation, temperature sensor.
- Display, Sound, Natural, Sleep, and Auto published as separate labeled accessories.
- UDP 6606 discovery with MAC-based rediscovery after DHCP changes.
- One-time authKey helper with North America / Europe / China regions and shared-account fallback.
- Homebridge Config UI schema and offline test suite.
